📊 Estruturas de Dados - Armazenando Informações Complexas

1. Listas (Arrays)

O que é uma lista?

Uma lista é um container que armazena múltiplos valores em uma sequência ordenada. Diferente de uma variável simples, você pode guardar vários dados e acessá-los por posição.

Exemplo em Python:
notas = [7.5, 8.0, 6.5, 9.0]
frutas = ["maçã", "banana", "laranja"]

print(notas[0]) # Acessa primeiro elemento: 7.5
print(frutas[-1]) # Acessa último elemento: laranja

notas.append(8.5) # Adiciona elemento
frutas.remove("banana") # Remove elemento
💡 Dica: Índices começam do 0! O primeiro elemento está na posição [0].

2. Dicionários (Mapas)

O que é um dicionário?

Um dicionário armazena dados em pares chave-valor. Em vez de usar números como índices, você usa palavras descritivas para acessar informações.

Exemplo em Python:
aluno = {
    "nome": "João",
    "idade": 20,
    "matricula": "2024001",
    "ativo": True
}

print(aluno["nome"]) # Saída: João
aluno["idade"] = 21 # Atualiza valor
print(aluno.keys()) # Lista todas as chaves
Lista vs Dicionário Lista Dicionário
Acesso Por número (posição) Por chave (nome)
Organização Sequencial e ordenada Sem ordem específica
Uso Dados similares em sequência Dados relacionados diversos

🏗️ Orientação a Objetos - Programação Estruturada

Entendendo Classes e Objetos

O que são Classes?

Uma classe é um "modelo" ou "blueprint" para criar objetos. Pense em uma classe como um molde de biscoito e os objetos como os biscoitos feitos daquele molde.

Estrutura básica de uma Classe:
class Carro:
    def __init__(self, marca, modelo, ano):
        self.marca = marca
        self.modelo = modelo
        self.ano = ano

    def descrever(self):
        return f"{self.ano} {self.marca} {self.modelo}"

meu_carro = Carro("Toyota", "Corolla", 2023)
print(meu_carro.descrever())
✓ Benefício: Código organizado, reutilizável e fácil de manter!

Atributos e Métodos

Qual é a diferença?

Atributos são dados/informações (o que o objeto tem). Métodos são ações/funções (o que o objeto faz).

Exemplo de Aluno com Atributos e Métodos:
class Aluno:
    # Atributos
    def __init__(self, nome, nota):
        self.nome = nome
        self.nota = nota

    # Métodos (ações)
    def passou(self):
        return self.nota >= 7

    def aumentar_nota(self, pontos):
        self.nota += pontos

aluno = Aluno("Maria", 6.5)
aluno.aumentar_nota(1.0)
print(aluno.passou()) # True

🛡️ Tratamento de Erros - Evitando Crashes

Try/Except - Capturando Erros

Por que tratar erros?

Quando algo dá errado no código, o programa "quebra" (crash). Com try/except, você pode antecipar possíveis erros e lidar com eles graciosamente.

Sem tratamento (problema):
nota = int(input("Digite sua nota: "))
print(nota / 10) # Se digitar "abc", dá erro!
Com tratamento (solução):
try:
    nota = int(input("Digite sua nota: "))
    print(nota / 10)
except ValueError:
    print("Erro! Digite apenas números.")
except ZeroDivisionError:
    print("Erro! Não pode dividir por zero.")
💡 Dica: Use try/except quando recebe input do usuário ou acessa arquivos.

📁 Trabalhando com Arquivos

Lendo e Escrevendo Arquivos

Como salvar dados persistentemente?

Até agora, os dados desaparecem quando o programa fecha. Arquivos permitem salvar informações permanentemente.

Escrevendo em um arquivo:
arquivo = open("dados.txt", "w") # "w" = write (escrever)
arquivo.write("Primeira linha\n")
arquivo.write("Segunda linha\n")
arquivo.close() # Sempre fechar!
Lendo um arquivo:
arquivo = open("dados.txt", "r") # "r" = read (ler)
conteudo = arquivo.read()
print(conteudo)
arquivo.close()
⚠️ Importante: Sempre feche os arquivos com close() para evitar problemas!

📦 Módulos e Bibliotecas

Reutilizando Código Externo

O que são bibliotecas?

Bibliotecas são coleções de código já pronto que você pode usar. Você não precisa reinventar a roda!

Exemplos de importação:
import math # Funções matemáticas
print(math.sqrt(16)) # Raiz quadrada: 4.0

import random # Números aleatórios
numero = random.randint(1, 100)

from datetime import datetime # Trabalhar com datas
agora = datetime.now()
print(agora)
💡 Dica: Python tem bibliotecas padrão para quase tudo. Explore: os, sys, json, requests, etc.

🎯 Projeto Prático Intermediário

Sistema de Gerenciamento de Alunos

✓ O que o programa faz: Cria, armazena e gerencia informações de alunos com cálculos de média.
Código simplificado:
class Aluno:
    def __init__(self, nome, matricula):
        self.nome = nome
        self.matricula = matricula
        self.notas = []

    def adicionar_nota(self, nota):
        self.notas.append(nota)

    def calcular_media(self):
        return sum(self.notas) / len(self.notas)

alunos = {}

# Criar alunos
alunos["001"] = Aluno("João", "001")
alunos["001"].adicionar_nota(8.0)
alunos["001"].adicionar_nota(7.5)

print(f"Média: {alunos['001'].calcular_media()}")

💡 Boas Práticas Intermediárias

DRY - Don't Repeat

Se repete 3+ vezes, crie uma função ou classe

Nomes Descritivos

Use calcular_media(), não calc()

Tratar Erros

Use try/except para entrada de usuário

Organização

Separe código em classes e módulos
