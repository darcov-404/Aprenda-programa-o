📌 O que é Programação?

Programação é o processo de dar instruções a um computador para realizar tarefas específicas. Um programa é uma sequência de comandos que o computador executa de forma ordenada.

Analogia Simples

Pensar em programação é como escrever uma receita de bolo. Você tem:

  • Ingredientes = Dados/Variáveis
  • Passos = Instruções/Código
  • Resultado = Output/Resultado Final

🔧 Conceitos Fundamentais

1. Variáveis

O que é uma variável?

Uma variável é um "container" que armazena um valor. Pense como uma caixa com um nome onde você guarda informações.

Exemplo em Python:
nome = "João"
idade = 25
altura = 1.75
é_programador = True

Tipos de dados comuns:

  • String: Texto ("João")
  • Integer: Número inteiro (25)
  • Float: Número decimal (1.75)
  • Boolean: Verdadeiro ou Falso (True/False)

2. Condições (If/Else)

Como tomar decisões no código?

Condições permitem que o programa execute diferentes ações baseado em situações específicas.

Exemplo em Python:
idade = 18

if idade >= 18:
    print("Você é maior de idade")
else:
    print("Você é menor de idade")
💡 Dica: Use = para atribuir valores e == para comparar.

3. Loops (Repetição)

Como repetir uma ação várias vezes?

Loops permitem que você execute o mesmo código múltiplas vezes sem repetir a escrita.

Loop While (enquanto):
contador = 1
while contador <= 5:
    print(contador)
    contador = contador + 1
Loop For (para):
for número in range(1, 6):
    print(número)

Quando usar cada um?

  • While: Quando não sabe quantas vezes vai repetir
  • For: Quando sabe o número exato de repetições

4. Funções

Como reutilizar código?

Funções são blocos de código que você pode chamar múltiplas vezes. Evitam repetição e deixam o código organizado.

Exemplo em Python:
def saudacao(nome):
    return "Olá, " + nome + "!"

mensagem = saudacao("Maria")
print(mensagem)

Partes de uma função:

  • def: Palavra-chave para criar função
  • Nome: Identificador da função
  • Parâmetros: Valores que a função recebe
  • Return: Valor que a função devolve

💪 Exemplo Prático Completo

Calculadora de Nota Final

O que o programa faz?

Calcula a média de 3 notas e diz se o aluno passou (nota >= 7).

Código em Python:
def calcular_media(nota1, nota2, nota3):
    media = (nota1 + nota2 + nota3) / 3
    return media

def verificar_aprovacao(media):
    if media >= 7:
        return "Aprovado!"
    else:
        return "Reprovado"

nota1 = 7.5
nota2 = 8.0
nota3 = 6.5

media = calcular_media(nota1, nota2, nota3)
resultado = verificar_aprovacao(media)

print(f"Média: {media}") print(resultado)

⭐ Boas Práticas

Nomes Significativos

Use nomes que descrevem o que a variável contém: idade em vez de x

Comentários

Escreva comentários explicando o "por quê", não o "quê"

DRY - Don't Repeat Yourself

Se repetir código 3+ vezes, coloque em uma função
