🎨 Design Patterns - Soluções Comprovadas

O que são Design Patterns?

Padrões de Design Reutilizáveis

Design Patterns são soluções testadas e aprovadas para problemas comuns em programação. Aprender padrões te torna mais produtivo e seu código mais profissional.

Singleton

Garante que apenas uma instância da classe existe em toda a aplicação.

Factory

Cria objetos sem especificar exatamente quais classes usar.

Observer

Define dependências entre objetos, notificando quando estado muda.

Strategy

Encapsula algoritmos para torná-los intercambiáveis.

Adapter

Converte interface de um objeto para outra que clientes esperam.

Decorator

Adiciona responsabilidades a objetos dinamicamente.

Exemplo: Padrão Singleton
class Database:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

db1 = Database()
db2 = Database()
print(db1 is db2) # True - mesma instância!

🧪 Testes Unitários - Código Confiável

Por que testar código?

Garantindo Qualidade

Testes verificam se seu código funciona como esperado. Profissionais escrevem testes para garantir que mudanças futuras não quebrem nada.

📌 Conceito: TDD (Test-Driven Development) = Escrever testes ANTES do código.
Exemplo com unittest:
import unittest

def calcular_desconto(preco, percentual):
    return preco * (1 - percentual / 100)

class TestDesconto(unittest.TestCase):
    def test_desconto_10_porcento(self):
        resultado = calcular_desconto(100, 10)
        self.assertEqual(resultado, 90)

    def test_desconto_invalido(self):
        resultado = calcular_desconto(100, 0)
        self.assertEqual(resultado, 100)

if __name__ == '__main__':
    unittest.main()
💡 Dica: Teste casos normais, casos extremos (0, valores negativos) e erros.

⚡ Programação Funcional - Novo Paradigma

Funções de Ordem Superior

Map, Filter e Lambda

Programação funcional trata funções como objetos de primeira classe. Permite código mais conciso e elegante.

Lambda e Map:
numeros = [1, 2, 3, 4, 5]

# Multiplicar cada número por 2
resultado = list(map(lambda x: x * 2, numeros))
print(resultado) # [2, 4, 6, 8, 10]

# Filtrar apenas números pares
pares = list(filter(lambda x: x % 2 == 0, numeros))
print(pares) # [2, 4]
Reduce (acumular):
from functools import reduce

numeros = [1, 2, 3, 4, 5]

# Somar todos os números
soma = reduce(lambda x, y: x + y, numeros)
print(soma) # 15

🔄 Decoradores - Modificando Comportamento

Funções que modificam funções

Decoradores Avançados

Decoradores são funções que modificam ou melhoram outras funções sem alterar seu código original. Muito usados em frameworks como Django e Flask.

Decorador simples:
def cronometro(func):
    def wrapper(*args, **kwargs):
        import time
        inicio = time.time()
        resultado = func(*args, **kwargs)
        duracao = time.time() - inicio
        print(f"Executado em {duracao:.4f}s")
        return resultado
    return wrapper

@cronometro
def tarefa_lenta():
    time.sleep(2)
    return "Pronto!"

tarefa_lenta()

⚙️ Generators e Context Managers

Generators - Economizando Memória

Produzindo valores sob demanda

Generators geram valores um de cada vez, economizando memória. Perfeito para trabalhar com grandes volumes de dados.

Generator vs Lista:
# Lista - aloca toda na memória
def numeros_lista(n):
    resultado = []
    for i in range(n):
        resultado.append(i)
    return resultado

# Generator - aloca sob demanda
def numeros_generator(n):
    for i in range(n):
        yield i

# Generator usa muito menos memória!
gen = numeros_generator(1000000)

Context Managers - With Statement

Gerenciando Recursos Automaticamente

Context managers garantem que recursos sejam liberados corretamente, mesmo se erros ocorrerem.

Context Manager customizado:
class Arquivo:
    def __init__(self, nome, modo):
        self.nome = nome
        self.modo = modo

    def __enter__(self):
        self.arquivo = open(self.nome, self.modo)
        return self.arquivo

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.arquivo.close()

# Uso: arquivo fecha automaticamente
with Arquivo("dados.txt", "r") as f:
    conteudo = f.read()

🚀 Programação Assíncrona - Concorrência

Async/Await - Múltiplas Tarefas Simultaneamente

Programação Não-Bloqueante

Async permite que o programa faça múltiplas tarefas "ao mesmo tempo" sem travar. Essencial para aplicações web e APIs.

⚠️ Complexo: Este é um dos tópicos mais difíceis. Recomenda-se dominar o resto primeiro.
Async/Await básico:
import asyncio

async def buscar_dados(url):
    print(f"Buscando {url}...")
    await asyncio.sleep(2) # Simula requisição
    return f"Dados de {url}"

async def main():
    # Executa 3 tarefas "simultaneamente"
    resultados = await asyncio.gather(
        buscar_dados("api1.com"),
        buscar_dados("api2.com"),
        buscar_dados("api3.com")
    )
    print(resultados)

asyncio.run(main())

📈 Performance e Otimização

Escrevendo Código Eficiente

Técnicas de Otimização

Código lindo é importante, mas código rápido também. Aprenda a identificar gargalos e otimizá-los.

💡 Princípio: "Premature optimization is the root of all evil" - Donald Knuth. Otimize apenas o que é lento!
Memoization - Cachear resultados:
from functools import lru_cache

@lru_cache(maxsize=None)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# Muito mais rápido que sem cache!
print(fibonacci(35))
Profiling - Descobrir gargalos:
import cProfile

def minha_funcao():
    # código lento
    pass

# Medir tempo de execução
cProfile.run('minha_funcao()')

🏛️ Arquitetura de Software

Estruturando Grandes Projetos

Separação de Responsabilidades

Quando projetos crescem, organizá-los bem é crucial. Vários padrões ajudam nisso.

MVC - Model View Controller:
# Model - Dados
class Usuario:
    def __init__(self, nome, email):
        self.nome = nome
        self.email = email

# Controller - Lógica
class UsuarioController:
    def criar_usuario(self, nome, email):
        return Usuario(nome, email)

# View - Apresentação
def exibir_usuario(usuario):
    print(f"Nome: {usuario.nome}")
    print(f"Email: {usuario.email}")
✓ Benefício: Cada camada tem uma responsabilidade clara. Mudanças em uma não afetam as outras.
